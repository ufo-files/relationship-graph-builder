# IBM Plex Mono

The regular and bold TrueType fonts are sourced from the official IBM Plex
repository at commit `bf260093582f04622aacc1e9f9ca604d7ccd0c42`:

- `packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf`
- `packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Bold.ttf`

They are embedded in presentation PDFs so both PDF chrome and SVG graph labels
retain the graph builder's monospace typography as selectable vector text.
See `IBM-PLEX-LICENSE.txt` for the SIL Open Font License.
